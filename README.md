## 📱 О приложении

**PodZHoc** - это современное Telegram Mini App для ставок на матчи Континентальной хоккейной лиги (КХЛ). Приложение предоставляет пользователям возможность делать ставки на реальные матчи КХЛ с красивым интерфейсом в стиле Tinder.

### ✨ Основные возможности

- 🏒 **Реальные матчи КХЛ** - автоматическое получение актуальных матчей из официального календаря
- 💰 **Система ставок** - интуитивный интерфейс для размещения ставок на команды
- 🎯 **Мгновенный бонус** - ежедневный бонус 1000 шайбочек
- 📊 **Мои ставки** - отслеживание активных и завершенных ставок
- 🏆 **Таблица лидеров** - рейтинг игроков по выигрышам
- ⚙️ **Админ-панель** - управление матчами, счетами и пользователями
- 📱 **Адаптивный дизайн** - оптимизирован для мобильных устройств

## 🚀 Быстрый старт

### Предварительные требования

- Node.js 18.x или выше
- npm или yarn
- Telegram Bot Token

### Установка

1. **Клонируйте репозиторий**
   ```bash
   git clone https://github.com/ВАШ_USERNAME/podzhoc-app.git
   cd podzhoc-app
   ```

2. **Установите зависимости**
   ```bash
   npm install
   ```

3. **Настройте переменные окружения**
   ```bash
   cp env.example .env
   ```
   
   Отредактируйте `.env` файл:
   ```env
   PORT=3000
   ADMIN_TOKEN=podzhoc_admin_2024_secret
   NODE_ENV=development
   ```

4. **Запустите приложение**
   ```bash
   npm start
   ```

5. **Откройте в браузере**
   ```
   http://localhost:3000
   ```

## 🗄️ База данных

### Таблицы

#### `users` - Пользователи
```sql
CREATE TABLE users (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    telegramId TEXT UNIQUE NOT NULL,
    firstName TEXT,
    username TEXT,
    balance INTEGER DEFAULT 1000,
    lastBonusTime INTEGER,
    createdAt INTEGER,
    updatedAt INTEGER
);
```

#### `bets` - Ставки
```sql
CREATE TABLE bets (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    userId TEXT NOT NULL,
    matchId TEXT NOT NULL,
    betType TEXT NOT NULL,
    amount INTEGER NOT NULL,
    selectedTeam TEXT NOT NULL,
    createdAt INTEGER,
    updatedAt INTEGER
);
```

#### `matches` - Матчи
```sql
CREATE TABLE matches (
    id TEXT PRIMARY KEY,
    homeTeam TEXT NOT NULL,
    awayTeam TEXT NOT NULL,
    startTime INTEGER NOT NULL,
    homeScore INTEGER DEFAULT 0,
    awayScore INTEGER DEFAULT 0,
    status TEXT DEFAULT 'scheduled',
    createdAt INTEGER,
    updatedAt INTEGER
);
```

#### `finished_matches` - Завершенные матчи
```sql
CREATE TABLE finished_matches (
    id TEXT PRIMARY KEY,
    homeTeam TEXT NOT NULL,
    awayTeam TEXT NOT NULL,
    startTime INTEGER NOT NULL,
    homeScore INTEGER NOT NULL,
    awayScore INTEGER NOT NULL,
    finishedAt INTEGER,
    createdAt INTEGER
);
```

## 🔧 API Endpoints

### Пользовательские API

#### `GET /api/matches`
Получение списка доступных матчей для ставок

#### `POST /api/bet`
Размещение ставки на матч
```json
{
  "telegramId": "string",
  "matchId": "string",
  "betType": "home|away",
  "amount": "number",
  "selectedTeam": "string"
}
```

#### `GET /api/user/bets`
Получение истории ставок пользователя
```json
{
  "telegramId": "string"
}
```

#### `POST /api/user/bonus`
Получение ежедневного бонуса
```json
{
  "telegramId": "string",
  "bonusAmount": "number"
}
```

#### `GET /api/leaderboard`
Получение таблицы лидеров

### Админские API

#### `GET /api/admin/matches`
Получение всех матчей (требует админский токен)

#### `POST /api/admin/update-score`
Обновление счета матча
```json
{
  "matchId": "string",
  "homeScore": "number",
  "awayScore": "number"
}
```

#### `POST /api/admin/finish-match`
Завершение матча
```json
{
  "matchId": "string"
}
```

#### `POST /api/admin/reset-all`
Сброс всех данных

#### `POST /api/admin/remove-anonymous`
Удаление анонимных пользователей
