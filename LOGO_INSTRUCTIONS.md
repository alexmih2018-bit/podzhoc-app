# 🏒 Инструкция по добавлению логотипа PodZHoc

## 📁 Куда поместить логотип

Поместите ваш PNG файл логотипа в следующую папку:
```
public/images/logo/
```

## 📝 Как назвать файл

Назовите файл точно так:
```
podzhoc-logo.png
```

## 🎨 Рекомендации по дизайну

### Размеры
- **Ширина**: 120px (автоматически масштабируется)
- **Формат**: PNG с прозрачным фоном
- **Соотношение сторон**: квадратное или прямоугольное (1:1 или 4:3)

### Стиль
- Используйте яркие цвета, которые будут хорошо видны на темном фоне
- Добавьте тень или обводку для лучшей видимости
- Избегайте слишком мелких деталей

## 🔧 Что уже настроено

✅ **CSS стили** - логотип будет:
- Автоматически центрироваться
- Иметь тень для лучшей видимости
- Увеличиваться при наведении (hover эффект)
- Адаптироваться под размер экрана

✅ **HTML структура** - логотип размещен:
- В верхней части приложения
- Над кнопкой "МГНОВЕННЫЙ ДОДЕП"
- В центре header секции

## 📱 Где будет отображаться

Логотип появится:
1. **В главном приложении** - в верхней части над кнопкой бонуса
2. **На всех устройствах** - мобильных и десктопных
3. **В Telegram WebApp** - при открытии через бота

## 🚀 После добавления файла

1. Поместите `podzhoc-logo.png` в папку `public/images/logo/`
2. Перезапустите сервер
3. Обновите страницу в браузере
4. Логотип должен появиться в верхней части приложения

## 🎯 Альтернативные названия

Если хотите использовать другое название, измените в файле `public/index.html` строку:
```html
<img src="images/logo/podzhoc-logo.png" alt="PodZHoc Logo" class="header-logo">
```

Замените `podzhoc-logo.png` на ваше название файла.

## 📞 Поддержка

Если логотип не отображается:
1. Проверьте, что файл находится в правильной папке
2. Убедитесь, что название файла точно совпадает
3. Проверьте, что файл в формате PNG
4. Перезапустите сервер
